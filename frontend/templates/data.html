Dataset Overview

Multimodal dataset used for lung cancer prediction using CT imaging, clinical data, and genomic features

CT Type Dataset (4-Class)

The CT Type dataset is used for multi-class classification of lung cancer types.

  • Adenocarcinoma
  • Large Cell Carcinoma
  • Squamous Cell Carcinoma
  • Normal

Images are loaded from train, test, and validation folders and mapped to numerical labels.

CT Binary Dataset

The CT Binary dataset is used for cancer detection (Cancer vs Normal).

  • Label 0 → Normal
  • Label 1 → Cancer

This dataset combines multiple CT sources including chest CT scans and IQ-OTHNCCD dataset.

Clinical Dataset

The clinical dataset contains patient health and lifestyle information used for prediction.

  • AGE
  • GENDER
  • SMOKING
  • YELLOW_FINGERS
  • ANXIETY
  • PEER_PRESSURE
  • CHRONIC_DISEASE
  • FATIGUE
  • ALLERGY
  • WHEEZING
  • ALCOHOL_CONSUMING
  • COUGHING
  • SHORTNESS_OF_BREATH
  • SWALLOWING_DIFFICULTY
  • CHEST_PAIN

Target variable: LUNG_CANCER (YES / NO) → converted to binary (1 / 0)

Genomic Dataset

The genomic dataset contains RNA sequencing gene expression data.

  • Non-numeric columns are removed
  • Low variance genes are filtered
  • Missing values are filled using mean
  • Data is normalized using StandardScaler

The processed data is converted into tensor format for deep learning models.

Multimodal Fusion System

The system uses a multimodal deep learning pipeline that integrates CT imaging, clinical data, and genomic features to generate a final lung cancer prediction.

Model Components:
  • CT Model: A ResNet50-based deep learning model extracts visual features from CT scans and performs both binary (Cancer vs Normal) and multi-class classification.
  • Clinical Model: A fully connected neural network processes patient features and generates a clinical risk score.
  • Genomic Model: A Variational Autoencoder (VAE) learns latent representations of gene expression data and computes genomic risk.
Fusion Strategy:
  • Outputs from CT, Clinical, and Genomic models are combined
  • Weighted fusion prioritizes CT features while incorporating patient and molecular data
  • Dynamic weighting adjusts importance based on confidence levels
  • Rule-based and deep learning fusion methods are used together
Final Prediction:
  • Binary Output → Cancer / Normal
  • Cancer Type → Adenocarcinoma / Squamous / Large Cell
  • Risk Level → Low / Medium / High
  • Survival Probability estimation
  • Clinical suggestions for treatment and follow-up
The final decision is generated using a fusion pipeline that combines all modalities into a single robust prediction.
